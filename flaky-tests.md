# Flaky tests
- 2026-10-22 `pn test` integration (`tests/terminal.test.ts`): `dedicated terminal tunnel > reports the shell's exit status after its last output` failed at line 334 because the lifecycle events were empty (`expected [] to deep equally contain { type: "exit", code: 3, signal: null }`). All 5 tests in the file passed on immediate rerun. Investigated 2026-10-29: 12 loaded runs of the file and 300 loaded repeats of the test all passed. Every way the agent side of the server relay can end sends an exit or error frame before closing, so an empty lifecycle needs the browser half of the relay to stop first (a browser frame the server rejects) or the server to go away. The likeliest cause is a concurrent `pn playwright` whose `preplaywright` hook then killed every listener on the reserved vitest port (fixed the same day: each hook now frees only its own suite's port). The assertion now reports the close code (1006 = socket dropped, 1005 = relay's own close) and the output, so the server log in `./log` plus that code should pin it down if it recurs.
